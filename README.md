# Maximilien Moreau — Portfolio

Site portfolio personnel à l'intersection du marketing digital, du développement web et de l'IA.

## Stack

- HTML5 / CSS3 / JavaScript (Vanilla)
- [Bootstrap 5.3](https://getbootstrap.com/)
- [Font Awesome 6](https://fontawesome.com/)
- Google Fonts (Inter, Sora)

## Fonctionnalités

- Design responsive (mobile-first)
- Mode sombre / clair avec persistance (`localStorage`)
- Bascule de langue FR / EN intégrée
- Animations au scroll

## Structure

```
profile/
├── index.html       # Page principale (hero, services, à propos, contact)
├── projets.html     # Page des projets
├── style.css        # Styles globaux + thème sombre
├── script.js        # Logique JS (thème, langue, interactions)
└── images/          # Assets visuels
```

## Déploiement

Le site est déployé via GitHub Pages sur la branche `gh-pages`.
